Photoplethysmography in four steps

  1. LED sends lightA light source illuminates the skin.
  2. Pulse changes blood volumeEach beat changes the volume in the tissue.
  3. Photodiode senses reflectionReflected light varies with the pulse.
  4. PPG waveform emergesRepeating peaks mark pulse events.

PPG measures a blood-volume-related optical signal. ECG measures the heart's electrical activity.

Firmware logic

every 10 ms (timer tick):
  raw = ADC_read(PA0)
  signal = moving_average(raw)
  threshold = update_threshold(signal)
  if rising_crossing(signal, threshold):
    if time_since(lastBeat) >= 300 ms:
      if lastBeat exists:
        IBI = now - lastBeat
        BPM = 60000 / IBI
        add BPM to recent-value average
      lastBeat = now
  display BPM when estimate is valid

Sampling at 100 samples/s with a 12-bit ADC (about 0.81 mV per count at 3.3 V). On timeout, the display shows "--" or "Searching".

Evaluating and limits

  • Stable contactDoes a clean waveform appear when the finger is still?
  • RepeatabilityDo resting readings settle near the same value?
  • DisturbanceDoes movement or loose contact cause errors?
  • Reference checkCompare with a manual 60-second count.

Motion, contact pressure, ambient light, low blood flow and a fixed threshold can all degrade the reading.
